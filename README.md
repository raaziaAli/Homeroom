# Homeroom

A random name wheel and a seating chart generator for the classroom. One HTML file, no ads, no sign-in, no sidebars to close before the lesson starts.

Built for a class of 20–25 with tables joined in 4s or in 2s.

**Live:** https://raaziaali.github.io/Homeroom

## What it does

**The wheel** picks a student, fairly and visibly.

- Three picking rules. The default, *no repeats until everyone's had a turn*, tracks the round and starts a fresh one automatically when everybody has been asked.
- A running count beside every name, so you can show the class that it really is even.
- Click a name to mark that student absent. They drop off the wheel and out of the seating chart.
- Undo a pick, put a student back on the wheel, and a timestamped log of the whole lesson.
- Press the spacebar to spin. The winner's name fills the screen at a size the back row can read.

**The seating chart** puts everybody somewhere sensible.

- Tables of 4 or 2, sized automatically from the class list. 25 students in 4s gives you 7 tables.
- Rules it tries to honour: keep two students apart, keep two students together, seat a student at a front table. It tests 600 arrangements and takes the best one, then tells you plainly if a rule wouldn't fit rather than quietly dropping it.
- Lock a student and shuffling never moves them.
- Drag a student onto another seat to swap the two, or tap two seats on a touchscreen.
- *Show it from where I stand* mirrors the chart so left and right match your view from the board.
- Print drops the dark theme for clean black-on-white, landscape, with the class name and date.

**Characters.** Every student gets their own small creature — horns or antennae, one to three eyes, four body shapes, ten colours. They're generated from a seed stored with the student, so a child's character is theirs and stays the same every day. Tap one to roll a new one. They appear in the name list, on the seating chart, and beside the winner when the wheel lands, which helps younger classes and anyone still learning each other's names.

## Class files

**Save file** writes `Your Class.homeroom.json` — the whole class, not just the names: absences, pick counts, characters, table layout, locks, front-row students and every seating rule.

**Open file** takes it back, on any computer. You can also drag a file anywhere onto the page.

Dropping a plain `.txt` or `.csv` list of names creates a new class named after the file. It reads the first column, so a register exported from a school system (`Student Name", 7B, 12`) works as it is, and a header row saying "Name" is skipped.

Opening a file always *adds* a class rather than overwriting one, so you can't lose work by opening the wrong file. With several classes saved, the message after saving offers one combined backup of all of them.

The app also keeps its state in browser storage between visits, but the file is the copy that matters — it survives a cleared cache and moves between machines.

## Publishing it

No build step, no dependencies, nothing to install.

1. Put `index.html` and this README in a repository.
2. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. Wait a minute, then open the URL above.

Serving it over HTTPS matters: the save dialog and the copy button both need a secure context, so they behave better on Pages than they do on a file opened from a USB stick.

## Notes

- Everything stays on the device. No accounts, no analytics, no network calls except the web font.
- The display font is Bricolage Grotesque, loaded from Google Fonts. A school network that blocks it falls back to Trebuchet — still readable, just less characteristic.
- Needs a current browser. Chrome and Edge give a proper *Save as* dialog; other browsers send the file to Downloads.
- Reduced-motion settings are respected: shorter spin, no confetti.

## Changing things

It's one file — styles at the top, application code at the bottom, no framework.

- Colours live in the `:root` block. `SEG_COLORS` sets the wheel segments, `HUES` the characters, `TABLE_TINTS` the table stripes.
- `TABLE_NAMES` holds the table names (Comets, Dolphins, Falcons…). Swap them for houses, planets, whatever your class is into.
- Seating preferences are weighted in `scoreSeats`: keep-apart 60, keep-together 14, front row 12. Raise a number to make that rule win more often.
- `avatarSVG` draws the characters. Each `switch` block is one feature — headgear, body, markings, eyes, mouth. Add a case to any of them and the variety grows on its own.
